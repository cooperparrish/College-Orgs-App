# College-Orgs-App

Create an app/website that will be used for clubs/Greek Life/school organizations. The app would consist of a calendar that would take the useful features from Timetree/Apple Calendar, Google Calendar. It would have a group messaging system similar to GroupMe or flare. The app would have location services to help keep track of the whereabouts of friends/Greeklife members. An app/website would basically be an all-in-one organization app. With social media features like Yikyak. Location services like Life 360. Later development of the app would be a service that Strip has for banking, but a program that would take all the Greek/payment options and put them into one secured program, just like how stripe hold banking information of people. I want the UI of this app/website to be like a Apples UI design Style(Human Interface Guidelines)
